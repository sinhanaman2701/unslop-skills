# Credits and licenses

This skill adapts ideas and text structure from the sources below. Keep this file in any copy or adaptation.

- **unslop** by Damir Sokolovsky ([@heydamir](https://x.com/heydamir), https://github.com/heydamir/unslop), licensed CC BY 4.0. The Direction lines, the pass order, the signs of slop, the "one bright moment, quiet chrome" principle, the visuals recipe and the story-video panel structure (Spacing, Colour, Type, Glass, People) come from it and from the video demonstrating it. This adaptation is iOS-first, with a web layer and stack adapters for Flutter, React Native and SwiftUI, and changes the values. Credit travels with any copy; videos produced from it carry "unslop by @heydamir".
- **visant-skills** by Visant / Pedro Jaques (MIT, Copyright (c) 2025-2026 Visant, https://github.com/pedrojaques99/visant-skills-public): slop catalog entries, the declutter test, the label / value / qualifier / evidence anatomy and element catalog (`visant-refine`), simulation-slider and control-panel rules, the forms, trust, chrome-budget and columns rules (`visant-frontend`), the copy prohibitions and fold-names-the-task rule (`visant-copy`), the preflight checks and scars, and the critique shape.
- **Impeccable** by Paul Bakaus (Apache-2.0, https://impeccable.style, https://github.com/pbakaus/impeccable): the four modes (Persuade, Operate, Read, Experience), the iOS slop test and native references, the craft floor and refuse list, the direction process (anti-template calibration, color strategy, scene-decides-light-or-dark), the bolder / quieter / distill / clarify / delight / overdrive / harden / onboard guidance, the DESIGN.md format, and the copy denylist (`docs/STYLE.md`).
- **platform-design-skills** by ehmo (MIT, https://github.com/ehmo/platform-design-skills): the Apple HIG rules for iPhone and iPad in `platforms/ios.md`. Impeccable's own iOS and Android references are distilled from the same work.
- **swiftui-microinteractions** by Vishal Paliwal (iAmVishal16), MIT, Copyright (c) 2026 (https://github.com/iAmVishal16/swiftui-microinteractions): glass rules, light-theme tonal stack, accent-from-artwork, image-tinted halo, adaptive light and dark guidance (see unslop-motion for the motion patterns).
- **frontend-design** skill (anonymous zip): the layout-first order of work (ASCII wireframe, then theme, then animation, then code). Its theme presets and font list were reviewed and deliberately not adopted: they are the templates the other sources warn against.
- The tweet describing a "de-slop UI" skill built from frames of a video, and the manifesto tweet calling for new aesthetics and "excessive experimentation": the first shaped the per-pass token-panel report; the second shaped the opt-in bold-direction protocol in `direction-file.md`.
- **Web layer** (`platforms/web.md`, `stacks/web.md`): WCAG 2.2 AA success criteria (W3C), web.dev guidance on Core Web Vitals and responsive design, and the web slop and detector rules read from unslop, visant-frontend and Impeccable (see the research ledger).
